🚀 DÉMARRAGE RAPIDE (Choisir une option):

OPTION 1: Docker (RECOMMANDÉ - La plus simple)
──────────────────────────────────────────────
  $ cd SmartShopDb
  $ docker-compose up
  
  Puis ouvrez: http://localhost:3000

OPTION 2: Installation Manuelle
────────────────────────────────
  Terminal 1 (Backend):
    $ cd SmartShopDb/backend
    $ cp .env.example .env
    $ npm install
    $ node scripts/initDatabase.js
    $ npm start
  
  Terminal 2 (Frontend):
    $ cd SmartShopDb/frontend
    $ npm install
    $ npm start

OPTION 3: Script Automatique
─────────────────────────────
  Windows:
    $ SmartShopDb\setup.bat
  
  Mac/Linux:
    $ ./SmartShopDb/setup.sh

🎯 MOTEUR DE RECOMMANDATION:

Le cœur du système utilise Neo4j pour fournir:
  ✅ Co-achats (produits achetés ensemble)
  ✅ Recommandations du panier (articles similaires)
  ✅ Produits populaires par catégorie
  ✅ Suggestions basées sur l'historique

Structure graphique:
  (:Order)-[:CONTAINS]->(:Product)-[:BELONGS_TO]->(:Category)
